>_ ABOUT NAS IO BOT [SYSTEM_SPEC]

Nas IO Bot is an automated Discord membership verification and subscription enforcement bot integrated with website accounts.

  • Gmail Registration: Requires users to register their Gmail address on the website before joining the Discord server.
  • MongoDB Database: Saves user profiles and Discord registration states securely to a MongoDB Cloud Database.
  • Subscription Audit: Checks website subscription status against active Discord members.
  • Auto-Kick Enforcement: Automatically kicks members if they are not subscribed or if their subscription expires.
