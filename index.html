>_ ABOUT NAS IO BOT

Nas IO Bot is an automated Discord membership verification and subscription enforcement bot integrated with website authentication.

  • Gmail Verification: Requires users to register their Gmail address on the website before joining the Discord server.
  • MongoDB Storage: Saves user profiles, Discord IDs, and registration metadata securely to a MongoDB Cloud Database.
  • Subscription Audit: Checks website subscription status against active Discord members.
  • Auto-Kick Enforcement: Automatically kicks members if they are unsubscribed or if their subscription expires.
